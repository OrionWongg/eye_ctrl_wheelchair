# 自动防卡与有限脱困修复

日期：2026-10-16。

按用户确认的六条规则修改：检测没有朝目标推进或左右振荡；先停车再调整局部接近路线；只在可观测安全区域内尝试有限前进/小角度转向；禁止盲区倒车及旋转扫入未知后方；有限重试后停车；进入门洞和墙角前验证完整后续通路。

没有新增人工确认动作，没有倒车指令，没有降低或修改固定动作速度。

## 实现

- `automatic_recovery.py`：任务级进展/振荡监测、停车握手、三个不同候选目标、失败路径记忆、自动回到原目标重规划、次数/时间上限。
- `observability.py`：当前扫描的可观测自由空间，后方默认未知；扫描时刻的里程计插值，不外推、不用历史通行轨迹填补盲区。
- `route_safety.py`：整条局部路径的车体扫掠、障碍碰撞、可观测范围和出口制动空间预检。
- `planner.py` / `navigation.py` / `nodes.py`：统一接入运动预测与任务控制；只有明确的规划受阻/卡住原因进入重试，急停和健康故障照常立即停车。

候选目标默认前方 25 cm、左 5°、右 5°，每个必须通过检查才执行。每任务最多三个候选，脱困流程最多 15 秒，动作和完整停车预测都必须保持在有限范围内。没有安全候选时允许零移动停车，不保证每个卡点都能脱困。

门洞原有安全余量、动作 TTL、输入/传感器超时以及 50 ms 计算保护不变。所有新局部路线在执行前检查整车后续通路，门洞候选的完整接近—转向—离开几何检查同时应用于实际导航服务。
