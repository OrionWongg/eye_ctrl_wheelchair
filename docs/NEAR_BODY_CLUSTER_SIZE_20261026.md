# base_link 半径1 m内的单帧回波簇尺寸预统计

2026-10-26：当前 ROS_DOMAIN_ID=0、ROS_LOCALHOST_ONLY=0 下仅发现 /parameter_events 和 /rosout，没有在线点云。本次使用之前保存的60秒静态采样，非当前驾驶现场采样。未修改在线过滤或发送运动命令。

## 范围与方法

输入为 noise_persistence_20261026/frames.npz，右588帧、左593帧，总1181帧。每台雷达逐帧独立统计，不融合时间或双雷达。坐标为base_link，水平距离sqrt(x²+y²)<=1 m，排除内部车体矩形X=[-0.45,0.55]、Y=[-0.30,0.30]，保留当前ground_z=-0.456、ground_tolerance=0.08、obstacle_height=0.90规则中的障碍点（含低于地面容差的异常回波）。共39376条障碍回波，单帧中位数4点、P95为86点、最大121点。

旧采集只保存距车体矩形不超过68 cm的支撑区域，因此1 m圆左右边缘有少量缺失，本报告是已有覆盖区的预统计，不能称为完整半径1 m统计。新collect.py已改为采集水平半径1.08 m，现场话题恢复后可重新采集完整范围。

聚类为三维欧氏连接分量，分别比较3、5、8 cm邻接距离。通过链式连接形成的簇可以大于邻接距离；无最小点数，单点也记为簇。尺寸为观测点包围盒跨度，不是实体真实尺寸。簇计数是逐帧观测次数，不是唯一物体个数。

| 邻接距离 | 簇观测数 | 单点簇比例 | ≤3点簇比例 | ≤3点簇包含的回波占比 |
|---|---:|---:|---:|---:|
| 3 cm | 3421 | 33.91% | 54.55% | 7.22% |
| 5 cm | 1116 | 35.30% | 42.11% | 1.42% |
| 8 cm | 916 | 30.35% | 35.48% | 0.96% |

## 5 cm连接距离下的尺寸

| 点数 | 簇观测数 | XYZ跨度中位数（cm） | XYZ跨度各自P95（cm） |
|---|---:|---|---|
| 1 | 394 | 0 / 0 / 0 | 0 / 0 / 0 |
| 2–3 | 76 | 1.10 / 1.80 / 0.67 | 3.42 / 3.82 / 2.93 |
| ≥4 | 646 | 26.43 / 24.30 / 11.90 | 29.00 / 26.37 / 14.90 |

2–3点簇的水平包围盒对角线中位数2.50 cm、P95为5.18 cm、最大7.37 cm。单点簇尺寸为零只是缺乏尺寸信息，不能推断为零尺寸物体。小簇距车身中位数约21 cm，离地最高点中位数约10–11 cm。

在本静态样本中，小簇与较大回波团在点数和跨度上存在分离，可以继续做5 cm连接距离、少于4点候选的离线标注对照；尚不能据此直接删除小簇。真实细杆、脚尖同样可能只有1–3点，3 cm连接距离还会把一些较大的回波团拆成多个小簇。没有标注，不能把减少比例解释为噪声去除准确率。
