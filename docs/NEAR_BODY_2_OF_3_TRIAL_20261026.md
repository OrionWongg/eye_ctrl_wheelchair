# 近车体稀疏回波 2/3 帧静态试验

> 历史记录：该滑动窗口实现已被单帧聚类替代，当前入口与规则见 [聚类滤波说明](NEAR_BODY_CLUSTER_FILTER_20261026.md)。

独立静态测试默认启用，无控制器或运动输出：

```bash
cd ~/eye_ctrl_wheelchair
./scripts/test_single_lidar_costmap.sh 201
# 或 202；先退出上一轮，再对照关闭过滤：
SPARSE_PERSISTENCE_ENABLED=false ./scripts/test_single_lidar_costmap.sh 201
```

已运行的进程需退出重启。正常硬件驾驶默认关闭；本次没有启动硬件或发布运动命令。

规则：地面分类和距离过滤后的当前障碍点，距规划车体矩形不超过60 cm，8 cm三维邻域少于4点（含自身）才需要确认。最近3个有效新帧中至少2帧在8 cm内有任意障碍回波才保留；当前帧必须命中。不输出历史点，保存的是未过滤的障碍历史。历史不足两帧、时间倒退或相邻传感器帧间隔超过150 ms时清空历史并保留当前点。原时间戳及新鲜度检查保留。

双雷达模式要求两台都更新才推进窗口，邻域密度使用合并点云，可能比文档中逐雷达计算更容易保留点；单雷达测试无此差异。候选匹配基于base_link，没有运动补偿，仅用于轮椅静止时对照。约10 Hz时，新候选通常增加100 ms确认延迟，非连续命中可能为200 ms。启动/断帧时保留点，因此不是所有闪点都会被过滤。

若某个扫描角度有未确认点，整角度输出inf，避免用该点后方的更远回波错误清除自由空间（同角度的已确认近点也可能暂时不输出）。inf不主动清除地图，旧占据仍按现有history_window保留，未知区域仍可能阻挡。观察RViz时应比较稳定实物与闪点；真实细杆、脚部及动态障碍的检出率尚未验收。

验证：硬件桥接41项测试通过，包含新增的2/3命中、孤立点、断帧/时间倒退、密集与远处回波测试；未做现场效果验收。
