## 目标与链路

眼镜/键盘提供前左右驾驶意图；空旷时执行标定满幅，障碍附近由原生Nav2 DWB跟踪已有路径并提供连续速度，底层通过原ESP32 BLE HID接口操控iPad。保留眼镜协议、确认逻辑和原有停止/授权机制。

## 实现

- 增加五方向按键标记、三档幅度录制及鼠标平面遥控录制；录制开关为界面按钮。
- 鼠标位置即时转换iPad目标坐标，显示操控轨迹、预测/实测速度及空间轨迹；保留原始odom、TF、控制事件用于分析。
- 共享五方向速度映射：前进0.548m/s，左/右转+0.821/-0.800rad/s，左前(0.394,+0.581)，右前(0.384,-0.590)。这些是初值，整数HID步长导致量化。
- 修复NumPy int64不能JSON序列化的问题。
- 原iPad导航接口支持连续v/ω映射；桥接可透传连续速度。Executor将速度与原安全授权配对，不再重新量化成固定速度。
- 连续导航使用现有全局路径服务和原生DWB FollowPath；DWB接收/取消由下游适配器负责。新增continuous_navigation开关，旧模式可保留。
- RViz原目标接口通过/goal_pose或/move_base_simple/goal接入同一执行链路，run_hardware_rviz.sh默认开启连续导航。
- ODIN世界系线速度经姿态旋转与杆臂补偿后发布车体速度；拟合控制中心为base_link的(-0.266192,+0.078385,0)m，仍需几何实测确认。
- 保留当天已有的路径跟踪、Smac适配、可视化与运行库安装脚本修改。

## 启动

传感器：

```bash
ROS_DOMAIN_ID=0 ROS_LOCALHOST_ONLY=0 ./scripts/start_sensors.sh
```

目标点与键盘：

```bash
ROS_DOMAIN_ID=0 WHEELCHAIR_ROS_DOMAIN_ID=0 ROS_LOCALHOST_ONLY=0 bash scripts/run_hardware_rviz.sh
```

独立鼠标录制（不能与导航控制器同时占用串口）：

```bash
ROS_DOMAIN_ID=0 ROS_LOCALHOST_ONLY=0 bash scripts/mouse_cmd_vel.sh
```
